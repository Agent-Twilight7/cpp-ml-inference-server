C++ ML Inference Server

An image-recognition model served by a high-performance C++ server. Many users send images at once; the server groups their requests into batches so the GPU processes them together, serving far more people at the same speed.

connecting…
1 · Requests arrive

Many clients at once

Each sends one image over HTTP to a custom epoll-based C++ network layer.

2 · Dynamic batching

Group, don't queue

The batcher waits up to a couple of milliseconds and packs up to 16 requests together.

3 · One GPU run

Results split back

The whole batch runs on the model in one call; each client gets its own answer.
